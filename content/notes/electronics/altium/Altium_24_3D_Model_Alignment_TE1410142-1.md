# Altium Designer 24.10.1：3D 模型与封装焊盘精确对齐教程

**示例器件：TE 1410142-1；适用文件：PCB 封装库 `.PcbLib`；日期：2026-11-02。**

本文是可重复使用的操作教程。目标是将 TE STEP 模型的方向、平面位置和安装高度调整正确，并保持已按厂家图纸建立的焊盘孔位不变。

> 本文未读取你的实际 STEP 和 PcbLib 文件，因此不预设 Rotation X/Y/Z、Location X/Y 或高度的最终数值。不同版本模型的原点与初始姿态可能不同，应使用实际安装面和引脚中心定位。

## 1. 对齐的基本原理

需要分别解决三个问题：

| 问题 | 调整对象 | 推荐方法 |
| --- | --- | --- |
| 模型侧躺、倒置、插口朝向不对 | 三维姿态 | 安装面贴板，再调整 Rotation Z |
| 引脚与焊盘孔整体错开 | XY 平面位置 | 创建引脚中心捕捉点，再吸附到孔中心 |
| 外壳悬空或沉入 PCB | Z 向高度 | 用 Set Body Height 指定安装点高度 |

建议顺序：**先摆正 → 再贴板 → 再对齐 XY → 最后检查三个位置。**

转动观察视角不会改变模型本身的位置或姿态。只有移动 3D Body、修改其属性或使用定位命令，才会改变模型。

## 2. 示例器件与准备资料

TE 1410142-1 是 MULTIGIG RT 2 垂直背板插座，产品页面标注为 144 位、9 排、16 列，带右端导向结构。具体孔阵列、孔径、编号和机械尺寸应依据 TE Product Drawing 核对，不能仅凭产品摘要推导全部孔位。

准备以下资料：

1. TE 1410142-1 的 STEP 文件，解压后一般为 `.stp` 或 `.step`。
2. TE 产品图纸，查看推荐 PCB 孔位布局及其观察方向。
3. 已建立焊盘和安装孔的 `.PcbLib`。

特别确认图纸的视图是连接器插合面、安装面还是 PCB 顶视图。“右端导向”不能直接理解为当前屏幕右边，必须结合视图判断。

## 3. 打开封装与导入模型

### Step 3.1 打开目标封装

1. 在 Altium Designer 中打开 `.PcbLib`。
2. 在 PCB Library 面板中选择 1410142-1 对应封装。
3. 保存一个操作前版本，便于恢复。
4. 先检查一个角部焊盘的编号及坐标，确认后续能找到它。

**目的：**建立明确的定位基准，避免把模型引脚对到相邻孔。

### Step 3.2 放置 STEP 模型

如果已放置模型，跳过本步骤。

1. 选择 **Place → 3D Body**。
2. 根据出现的界面选择通用模型类型，加载或嵌入 STEP 文件；相关字段可能显示为 **Generic / Generic 3D Model**、**Embed Model**。
3. 在封装附近单击放置。
4. 右键或 Esc 退出重复放置。

建议嵌入模型，便于封装库随文件传递。暂时不必追求位置准确。

### Step 3.3 了解 3D Body 属性

选中或双击模型，查看 Properties 面板，确认当前编辑对象为 **3D Body**。

| 属性 | 含义及使用方法 |
| --- | --- |
| Location X / Y | 3D Body 参考点在封装中的坐标；未必是某个引脚或外壳中心 |
| Rotation X / Y | 绕相应轴旋转，用于调整模型俯仰、翻转 |
| Rotation Z | 在板平面内调整朝向 |
| Board Side | 模型所在板面；本示例按顶面安装处理 |
| Standoff Height | 与模型离板高度有关的参数；通孔模型不能简单以数值为零判断正确 |
| Snap Points | 自定义捕捉点列表，用于精确抓取和定位 |

不要为了让模型原点重合而移动整个焊盘阵列。模型参考点与封装原点不同属于正常情况。

## 4. 在 3D 模式中辨认安装面

### Step 4.1 切换与旋转视角

1. 将鼠标移回编辑工作区。
2. 按 **3** 进入 3D Layout Mode。
3. 使用鼠标滚轮放大或缩小。
4. 按住 **Shift + 鼠标右键**并拖动，旋转观察视角。

如果快捷键无效，检查键盘焦点是否停留在 Properties 输入框，或使用 **View → 3D Layout Mode**。

### Step 4.2 辨认 1410142-1 的部位

| 部位 | 安装后的关系 |
| --- | --- |
| 插合口 | 位于 PCB 上方，朝向配对板卡 |
| 壳体安装支撑面 | 按产品图纸落在 PCB 顶面 |
| 压接针尾 | 朝向 PCB，并进入对应金属化孔 |
| 导向结构 | 方向和位置与图纸及封装一致 |

**不要将针尾最下端当作贴板面。** 通孔针尾应向板内延伸，必要时伸出板底。

如果模型没有清晰的整块底面，应寻找厂家规定的支撑凸台或安装基准面，而不是任意选择一个水平面。

## 5. 让模型安装面贴合 PCB

### Step 5.1 使用 Align Face With Board

1. 保持在 3D 模式，调整视角，使底部安装支撑面可见。
2. 选择 **Tools → 3D Body Placement → Align Face With Board**。
3. 查看底部状态栏提示，先点击目标 3D 模型。
4. 模型进入面选择状态后，将鼠标移到实际安装支撑平面。
5. 确认高亮的是正确平面，再单击。
6. 旋转视角，确认插合口在板上方、针尾朝下。

**原理：**该命令将所选平面与对应板面重合，可同时改变方向和高度。只支持选择平坦表面。

**成功判据：**实际安装支撑面落在板面，针尾进入 PCB 方向，连接器没有倒置。

### Step 5.2 调整平面朝向

如果模型已经站正，但针阵列长边或导向端方向不对：

1. 选中模型，打开 Properties。
2. 记录当前 Rotation 值。
3. 调整 **Rotation Z**，按需要增减 90° 或 180°。
4. 每次修改后按 Enter，观察结果。
5. 核对图纸的观察方向、引脚编号和导向端。

若是侧躺或倒置，可调整 Rotation X/Y，但旋转后应重新检查安装面和高度。优先一次改一个轴，避免多项同时修改后无法判断原因。

## 6. 创建引脚中心捕捉点

### Step 6.1 选择基准引脚

优先选择阵列角部、能确认编号、针尾几何清晰的引脚。将其记为 **基准引脚 A**；在焊盘阵列中找到它对应的 **焊盘 A**。

不要默认模型屏幕左下角就是 1 脚。必须通过图纸、外壳特征及孔阵列确认。

### Step 6.2 启用捕捉点显示

1. 按 **L** 打开 View Configuration，或通过 **View → Panels → View Configuration** 打开。
2. 找到 **Layers & Colors → System Colors**。
3. 启用 **3D Body Reference Point**。
4. 启用 **3D Body Custom Snap Points**。

两种点的区别：Reference Point 是模型自带参考位置；Custom Snap Point 是你自行定义的准确抓取位置。

### Step 6.3 两个对角顶点取中点

1. 按 **3**，从底部放大基准引脚 A 的针尾端面。
2. 选择 **Tools → 3D Body Placement → Add Snap Points From Vertices**。
3. 按状态栏提示点击模型。
4. 按 **空格键**切换模式，直到状态栏提示选择两个顶点并在中点放置捕捉点。
5. 点击针尾矩形端面的第一个角点。
6. 点击同一端面的对角角点。
7. 查看生成的中心捕捉点。
8. 右键或 Esc 退出。

**为什么选对角点？** 矩形对角点的中点是端面中心；同一条边的两个端点只会得到边中点。

### Step 6.4 压接针几何的特殊情况

如果针尾包含鱼眼、开槽或不规则几何：

- 优先寻找规则、关于针脚轴线对称的端面顶点。
- 两个点应处于同一个截面，且关于中心对称。
- 不要把不同高度、不同截面的两个角点随意配对。
- 看不到可靠中心时，换一根几何清晰的针，或使用有明确轴线的定位特征。
- 不能确认模型顶点的几何意义时，不要用猜测的中点作为精确基准。

捕捉点在针尾末端时，可以用于后续 2D 的 XY 定位；它的 Z 高度不应拿来当作壳体安装高度。

## 7. 在 2D 模式中对齐孔中心

### Step 7.1 抓住正确的点

1. 按 **2** 回到 2D Layout Mode。
2. 找到刚才创建的 Custom Snap Point。
3. 放大模型和基准焊盘 A。
4. 清除其他对象选择，避免同时移动焊盘或丝印。
5. 将鼠标准确放在自定义捕捉点上，按住左键拖动模型。
6. 确认模型跟随鼠标移动，并且所抓取的位置就是该捕捉点。

若抓取位置不准确，取消并重试。可检查 **Preferences → PCB Editor → General → Snap to Center** 设置。对象吸附设置与网格设置也会影响定位。

### Step 7.2 吸附到对应焊盘中心

1. 保持模型跟随鼠标。
2. 将基准捕捉点移到焊盘 A 的中心。
3. 确认吸附到焊盘/孔中心，而不是铜环边缘或附近网格点。
4. 放下模型。
5. 按 Esc 结束操作，保存封装库。

**成功判据：**在 2D 投影中，引脚中心捕捉点与目标孔中心重合。

无需把模型 Location X/Y 改成零。它们是模型参考点坐标，不是所建捕捉点的目标坐标。

### Step 7.3 如果拖动时总选错对象

1. 检查 Selection Filter，启用 **3D Bodies**。
2. 暂时关闭会被误选的其他对象类型，操作结束后恢复。
3. 检查 3D Body 是否被锁定。
4. 确认 3D Body 所在机械层可见。
5. 如果存在多个重叠对象，使用选择列表辨认 **3D Body**。

## 8. 单独校正安装高度

如果 XY 已对齐，但壳体悬空或下沉，使用以下方法，不必重新对齐焊盘。

1. 按 **3** 进入 3D 模式。
2. 选择 **Tools → 3D Body Placement → Set Body Height**。
3. 点击目标模型。
4. 按状态栏提示，选择实际安装支撑面上的一个顶点或已建立的捕捉点。
5. 在 **Choose Height Above Board Top Surface** 对话框中选择 **Board Surface**。
6. 点击 OK。
7. 从侧面检查壳体与板面的关系。

如果安装基准点需要离板一定距离，选择 **Custom** 并输入厂家图纸要求的高度。输入值针对刚选择的点，不是随意针对模型原点。

> 对 1410142-1，不要选择针尾末端并设置为 Board Surface，否则会把整只连接器抬高。也不要用 PCB 厚度直接替代安装高度。

## 9. 三处检查：确认不是只对准一个孔

| 检查位置 | 怎么检查 | 能发现的问题 |
| --- | --- | --- |
| 基准引脚 A | 确认针中心与孔中心重合 | 整体平移错误、选错孔 |
| 同一排远端引脚 B | 放大检查针孔中心 | 角度错误、间距或模型问题 |
| 另一排引脚 C | 选不与 A/B 共线的位置 | 排间距、镜像、行列方向问题 |

另外检查：

1. 导向结构与图纸方向一致。
2. 安装支撑面与 PCB 表面吻合。
3. 针尾伸入孔中，而不是停在板面上方。
4. 焊盘编号对应图纸，不能只确认外形重合。
5. 所有焊盘、安装孔和丝印坐标没有被误移动。

在 PcbLib 中完成后，可把封装放到一个有实际板厚的测试 PCB 中，从板底与侧面复查。板厚用于确认针尾伸出关系，不应改变针脚 XY 孔位。

## 10. 用坐标计算进行小幅平移

如果方向已经正确，且能准确取得同一坐标系下模型特征点与焊盘中心的坐标，可用差值平移：

```text
ΔX = 目标焊盘中心 X − 当前模型引脚中心 X
ΔY = 目标焊盘中心 Y − 当前模型引脚中心 Y

新的模型 Location X = 原模型 Location X + ΔX
新的模型 Location Y = 原模型 Location Y + ΔY
```

例如：模型引脚中心为 (12.30 mm, 5.10 mm)，目标孔中心为 (12.00 mm, 5.50 mm)，则模型应整体 X 减少 0.30 mm、Y 增加 0.40 mm。

该例仅说明平移计算，不是 1410142-1 的真实定位数值。不要把模型内部局部坐标直接当作封装坐标使用；模型旋转后尤其需要注意坐标系。

## 11. 常见问题排查

| 现象 | 可能原因 | 处理方法 |
| --- | --- | --- |
| 所有针脚等量偏移 | XY 未对齐或抓取点错误 | 从正确中心捕捉点重新移动 |
| 一端准，另一端越来越偏 | 角度、间距或型号错误 | 核对 Rotation 和图纸，再比较远端孔 |
| 一排准，另一排不准 | 排间距、镜像或行列方向错误 | 检查第三个不共线的引脚 |
| 外壳悬空 | 误把针尾端面贴板 | 重新选择支撑面或 Set Body Height |
| 外壳沉入板内 | 高度或 Board Side 不正确 | 核对安装点高度与板面 |
| 无法选到安装面 | 面被遮挡或不是平面 | 旋转视角，选择支撑平面 |
| 捕捉点不见了 | 显示关闭或尚未创建成功 | 检查 System Colors 与 Snap Points 列表 |
| 拖动总是选到焊盘 | 重叠对象、过滤设置 | 临时仅允许选择 3D Bodies |
| 移动总落在网格而不是孔中心 | 对象吸附未生效 | 检查吸附设置并适当缩小网格 |
| 针阵列准但导向端反了 | 观察方向或模型方向错误 | 结合图纸重新判断，不能只看对称针阵列 |
| PCB 中还是旧模型 | 仅修改了库，板上实例未更新 | 保存库并通过 Update From PCB Libraries 检查和应用更新 |

更新 PCB 时阅读变更列表，确认焊盘、孔和其他对象没有非预期变化。仅在 PCB 中局部调整模型，不会自动成为源封装库的永久修改。

## 12. 完成检查清单

- [ ] 型号确认为 TE 1410142-1，STEP 与产品图纸对应。
- [ ] 明确图纸观察方向，确认基准引脚编号。
- [ ] 安装支撑面贴合正确板面，针尾朝向 PCB。
- [ ] 基准引脚中心与对应焊盘孔中心重合。
- [ ] 远端引脚和另一排引脚同时对齐。
- [ ] 导向端方向正确。
- [ ] 安装高度正确，没有用针尾端面替代安装面。
- [ ] 焊盘坐标、孔径、编号没有因模型对齐而改变。
- [ ] 保存 PcbLib；若 PCB 已放置实例，已检查并更新。

## 13. 日常速查

1. **3**：进入 3D。
2. **Shift + 右键拖动**：观察模型底部。
3. **Tools → 3D Body Placement → Align Face With Board**：安装面贴板。
4. 必要时修改 **Rotation Z**：调整插口及导向端方向。
5. **Add Snap Points From Vertices**：在基准引脚中心建捕捉点；空格切换两点取中点。
6. **2**：回到 2D，从捕捉点拖动模型到对应孔中心。
7. **3**：复查基准、远端、另一排三个引脚。
8. 必要时使用 **Set Body Height** 校正高度，保存。
